# SmartCut Viewer 0.1.0 — проверка на другом ПК

Это отдельный локальный пробник Windows x64 (Windows 10 22H2 / Windows 11).
Он не обновляет основной SmartCut Pro и не подключается к серверу другого ПК.
Служба автоматически запускается на этом же ПК и слушает только 127.0.0.1:5192.

## Установка

Запустите `SmartCut.Viewer-0.1.0-Setup-win-x64.exe`.
.NET уже включён. Установщик проверяет/устанавливает Microsoft Visual C++ и
Microsoft Edge WebView2; для загрузки WebView2 может потребоваться Интернет.
Приложение пока не подписано сертификатом издателя; не отключайте защиту Windows.
Если защита блокирует запуск, сохраните точный текст сообщения для диагностики.

Portable: распакуйте весь архив. Если VC++/WebView2 отсутствуют, установите
официальные компоненты из `prerequisites`. Не переносите один EXE.

## Полный цикл

1. Скопируйте на этот ПК сохранённый `.smartcut` с рассчитанными картами.
   Для STEP используйте встроенные модели либо перенесите исходные STEP.
2. Запустите **«Конструктор — локальная проверка публикации»** из меню Пуск
   (в Portable — `SmartCut.WpfApp.exe` рядом с Viewer).
3. **Файл → Опубликовать на сервер…** → выберите этот `.smartcut` → выберите
   папку для производственной копии. Дождитесь успешной публикации.
4. Откройте `SmartCut.Viewer.exe`, нажмите **Обновить задания**, выберите задание.
5. Проверьте выбор профиля/хлыста, клик детали, 2D, 3D, общий PDF и STEP в папке.
6. **Взять в работу** → **Завершить** либо комментарий → **На доработку**.
7. Закройте/откройте Viewer: задание и история должны сохраниться.

Viewer не публикует проекты. «Открыть пакет» принимает только публикации,
уже зарегистрированные в локальной службе этого ПК, а не оригинал конструктора.
Пустой список при первом запуске нормален: сначала опубликуйте тестовый проект.
Удаление приложения не удаляет библиотеку `%LOCALAPPDATA%/SmartCut/production-pilot`.

## Ограничения

- Сетевой доступ, роли разных Windows-пользователей и настоящая Windows-служба
  ещё не включены. Не открывайте порт в роутере или брандмауэре.
- Пока нет автообновлений Viewer: следующие версии ставятся отдельным установщиком.
- Конструктор в комплекте предназначен только для проверки публикации;
  обычный SmartCut Pro 5.1.12 и Android 0.1.12 остаются отдельными продуктами.
- При ошибке 401 или занятом порте не удаляйте ключи и задания: пришлите сообщение.
