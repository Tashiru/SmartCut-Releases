# SmartCut Viewer

Отдельная ветка **Viewer** для просмотра производственных заданий.
Она не является каналом обновления основного SmartCut Pro или Android.

## Скачать локальный пробник 0.1.2

- [Установщик Windows x64](https://github.com/Tashiru/SmartCut-Releases/releases/download/viewer-v0.1.2-test/SmartCut.Viewer-0.1.2-Setup-win-x64.exe)
- [Portable Windows x64](https://github.com/Tashiru/SmartCut-Releases/releases/download/viewer-v0.1.2-test/SmartCut.Viewer-0.1.2-Portable-win-x64.zip)
- [Подробное описание выпуска](https://github.com/Tashiru/SmartCut-Releases/releases/tag/viewer-v0.1.2-test)
- [Пошаговая инструкция](START-HERE.md)

Установщик допускает Windows 10 1903 (18362) и новее / Windows 11, x64. .NET входит в комплект. На 1903 запуск ещё требует проверки: эта ОС вне официальной поддержки Microsoft. В 0.1.2 из пакетов убраны отладочные PDB, из Setup — дубли установочных компонентов.
Установщик содержит подписанные Microsoft компоненты VC++ и WebView2;
для загрузки WebView2 при установке может понадобиться Интернет.
Само приложение пока не подписано сертификатом издателя.

## Для чего нужен Viewer

Конструктор готовит раскрои и публикует производственную копию. Оператор
просматривает карты и детали, открывает PDF/STEP и отмечает производственный статус.
Viewer не импортирует сборки, не пересчитывает раскрой и не публикует проекты.

- задания, профили и хлысты;
- выбор детали на карте, параметры, 2D и интерактивное 3D;
- общий PDF и STEP в Проводнике;
- «К работе», «В работе», «Выполнено», «На доработке»;
- ответственный и сохранённая история действий;
- локальный сервис, продолжающий работать после закрытия Viewer;
- производственная копия без изменения оригинала конструктора.

## Как проверить на другом ПК

Скопируйте сохранённый `.smartcut` на этот ПК. Запустите комплектный
«Конструктор — локальная проверка публикации» → **Файл → Опубликовать на сервер…**.
После публикации запустите Viewer → **Обновить задания**.
Первоначально пустой список — нормально: на новом ПК ещё нет публикаций.

Пробный конструктор включён только для проверки этого цикла. Установщик
ставится в отдельную папку и не меняет ассоциации `.smartcut`.

**Важно: пока это локальный пробник на одном ПК, не LAN-сервер.**
Подключение Viewer со второго ПК к первому ещё не включено.
Не открывайте порт 5192: он должен слушать только 127.0.0.1.
Viewer проверяет обновления при запуске; вручную — кнопкой «Обновления Viewer». Скачивание с прогрессом и отменой, проверкой размера и SHA-256, установка после подтверждения. Только канал Viewer. 0.1.1 можно установить сразу, без 0.1.0. Для пользователей 0.1.0 переход на 0.1.1 один раз выполняется вручную.

## Проверки

Первый выпуск прошёл 293 теста. Для 0.1.1 повторно пройдены все 37 тестов сервера/обновления, включая 5 новых проверок выбора канала, загрузки и уборки кеша.
Проверены публикация, неизменность оригинала, встроенный STEP, PDF,
запрет устаревших карт, отсутствие дубля при повторной отправке,
статусы/история после перезапуска. Карта, 2D, 3D и действия оператора
проверены в работающем приложении, включая точный STEP-образец OCCT с отверстиями.
Проверка на вашем другом ПК остаётся аппаратным тестом — совместимость
со всеми драйверами GPU заранее не гарантируется.
