## Что такое SmartCut Pro

SmartCut Pro — Windows-приложение для подготовки раскроя круглых, квадратных и прямоугольных труб, уголков и швеллеров. Программа читает геометрию деталей из STEP, определяет размеры профиля и параметры торцов, группирует одинаковые позиции и размещает их на хлыстах с учётом технологических ограничений.

Результат можно проверить в интерактивной 2D-карте и точном 3D-представлении, скорректировать вручную и выгрузить в PDF для производства.

## Возможности

- автоматическое распознавание труб и открытых профилей по STEP;
- импорт отдельных деталей и сборок из КОМПАС-3D;
- распознавание скосов, отверстий, вырезов и торцевых контуров;
- автоматический, генетический и ручной раскрой;
- дополнительный режим «Рез стыком» для разделения длинной детали между хлыстами;
- учёт ширины реза, направления раскроя и рабочих остатков;
- защита патронной зоны от отверстий и скосов;
- проверка совместимости соседних торцов;
- создание повторяемых карт из ещё не размещённых деталей;
- 3D-проверка сборки и каждого раскроенного хлыста;
- настраиваемое управление и куб базовых и изометрических видов;
- экспорт производственных карт и сводных данных в PDF;
- сохранение проектов, автосохранение и восстановление работы;
- локальный мобильный доступ по QR с одобрением телефона и ролями пользователей;
- автоматическая загрузка и установка обновлений.

## Что нового в версии 5.1.8

Это парное тестовое обновление Windows 5.1.8 и [Android 0.1.10](https://github.com/Tashiru/SmartCut-Releases/releases/tag/android-v0.1.10-test). Алгоритмы раскроя не менялись.

- Одна кнопка «Разрешить доступ» одобряет аккаунт и выбранный телефон. Старое частичное одобрение завершается тем же действием; роль и допуски других телефонов не меняются.
- Ошибки входа больше не выглядят как бесконечное ожидание одобрения. Телефон проверяет статус допуска примерно каждые 1,8 секунды.
- На ПК можно запомнить администратора и выйти из админ-панели. Сохраняется только токен сеанса, защищённый Windows DPAPI для текущего пользователя, не пароль.
- На связанном телефоне можно повторно войти с временным/новым паролем или после истечения сеанса без повторного QR. Временный пароль нужно сменить перед управлением расчётами.
- При удалении аккаунта удаляются и привязанные устройства: разрешение не переходит к новому пользователю с тем же логином. Проверены роли, отзыв доступа, смена и восстановление пароля.
- HTTPS-сервер по-прежнему работает только в локальной сети. Внешний доступ через мобильную сеть не включён; порт на роутере открывать нельзя.

Для проверки обновите **и ПК, и телефон**. Маршрут: «Аккаунт» → подготовить регистрацию или вход → главная → QR → одно «Разрешить доступ» в заявке телефона на ПК → проекты. До первого QR регистрация ещё не подтверждена выбранным ПК. Старое подключение без привязанного аккаунта потребует нового входа и QR; действующий запомненный сеанс восстанавливается. Для ещё не связанного телефона временный пароль выдаёт администратор на ПК.

Полный список изменений находится на страницах [релиза Windows](https://github.com/Tashiru/SmartCut-Releases/releases/tag/v5.1.8-test) и [релиза Android](https://github.com/Tashiru/SmartCut-Releases/releases/tag/android-v0.1.10-test). Предыдущие версии доступны в [списке выпусков](https://github.com/Tashiru/SmartCut-Releases/releases).

## Установка

1. Скачайте [`SmartCut.Pro-test-Setup.exe`](https://github.com/Tashiru/SmartCut-Releases/releases/download/v5.1.8-test/SmartCut.Pro-test-Setup.exe).
2. Запустите установщик и завершите установку.
3. Откройте SmartCut Pro через меню «Пуск» или ярлык на рабочем столе.

Установщик предназначен для Windows x64 и включает необходимые компоненты приложения. При первом запуске Windows может показать стандартное предупреждение SmartScreen для нового неподписанного издателя.

Для Android установите [SmartCut Mobile 0.1.10 APK](https://github.com/Tashiru/SmartCut-Releases/releases/download/android-v0.1.10-test/SmartCut.Mobile-0.1.10-test.apk) поверх прежней версии или нажмите «Проверить обновление приложения» в установленном клиенте. Удалять старую версию не нужно. Установку APK из GitHub Android может потребовать подтвердить как установку из стороннего источника.

## Автоматические обновления

Версия, установленная через `SmartCut.Pro-test-Setup.exe`, проверяет наличие обновлений и предлагает загрузить их из этого репозитория. После скачивания приложение закрывается, применяет пакет и запускается снова.

Если SmartCut был запущен из portable-папки или установлен старым установщиком, автоматическое обновление недоступно. В таком случае один раз установите актуальный Setup вручную.

## Какой файл скачать

| Файл | Назначение |
|---|---|
| `SmartCut.Pro-test-Setup.exe` | Рекомендуемая установка с последующими автообновлениями |
| `SmartCut.Pro-test-Portable.zip` | Ручной запуск без установки и автообновления |
| `SmartCut.Mobile-0.1.10-test.apk` | Android-клиент для просмотра и управления раскроем в той же сети |
| `SmartCut.Pro-*-full.nupkg` | Полный пакет для механизма обновления Velopack |
| `SmartCut.Pro-*-delta.nupkg` | Компактное обновление с предыдущей версии |
| `releases.test.json` | Служебный индекс тестового канала обновлений |

Обычному пользователю нужны только Setup или Portable. Файлы `nupkg` и `releases.test.json` приложение использует самостоятельно.

## Статус версии

SmartCut Pro 5.1.8 и SmartCut Mobile 0.1.10 распространяются через тестовый канал. Перед производственным использованием рекомендуется открыть несколько знакомых проектов, проверить распознанные размеры и визуально просмотреть 3D-карты. Для режима «Рез стыком» дополнительно проверьте длины фрагментов, положение отверстий и патронную зону. APK ещё требует проверки запуска и плавности жестов на реальном телефоне.

Если результат распознавания или раскроя выглядит неверно, сохраните исходный STEP и описание ожидаемого результата — это позволит воспроизвести и исправить конкретный случай.
